[SLIDE 20]
This is the Trading Manager Browser Window before a query has been run. You can see the Toolset Bar across the top with instrument types like Swap, Option, and FRA. The main area shows only a Main Group folder — no data yet, because no query has been executed.

[SLIDE 21]
After running a query, the Browser Window populates with results displayed in graphical form. Each coloured block represents a portfolio or instrument group, and you can drill in to see individual deals. This visual layout is how you navigate your trade data in Endur.

[SLIDE 22]
To run a query, select the Query icon on the toolbar — it looks like a question mark — or go to File and then Query from the menu bar. This opens the Query Manager where you can build and run searches across the database.

[SLIDE 23]
Inside the Query Manager, you enter search criteria on the right-hand side. The left side shows a running summary of all criteria you've added. Endur supports conditional operators: less than, greater than, equal to, less than or equal to, and the exclamation mark for not equal.

[SLIDE 24]
Query Defaults automatically pre-fill common filter criteria to keep database performance efficient. By default, Endur filters by Transaction Type, Transaction Status — showing only New and Validated deals — and by the Internal Portfolios you're authorised to access. You can override these in the query window.

[SLIDE 25]
For more complex searches, Endur supports direct SQL entry. Click the drop-down arrow on the far left of the Query window to open a free-format SQL field. Type your SQL expression, then click the checkmark to run the query with that additional filter applied.

[SLIDE 26]
Endur uses shorthand conventions to speed up date and amount entry. For time periods: d for days, w for weeks, m for months, and y for years — so typing 5d means five days from today. For amounts: k means thousands and m means millions — so 3k becomes 3,000. You can combine these with operators, like greater than 5d.

[SLIDE 27]
The Table Viewer is Endur's standard grid for displaying lists of data — trades, parties, prices, or any other record type. The same Table Viewer appears consistently throughout the system, so once you know how to use it in one place, you know how to use it everywhere.

[SLIDE 28]
Any data displayed in the Table Viewer can be exported directly to Microsoft Excel. This is useful for further analysis, reporting, or sharing data outside the system. The exported spreadsheet preserves the column structure exactly as it appears on screen.

[SLIDE 29]
The Table Viewer has a built-in search function. Press F2 or use the Search menu to open the search dialog. You can search forward or reverse through the results, choose which column to search in, and toggle case-sensitive matching on or off.

[SLIDE 30]
The Table Viewer is fully configurable. You can add or remove columns, change their order, adjust column widths, and save the layout as a named view. The configuration dialog also lets you set sort order and pin certain columns so they stay visible when you scroll horizontally.
